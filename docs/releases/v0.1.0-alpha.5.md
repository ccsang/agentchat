# AgentChat v0.1.0-alpha.5（未发布）

该标签在 Linux arm64 的并发检查中失败，未发布安装包。功能及并发修复随 v0.1.0-alpha.6 交付，以下保留原拟发布内容。

Claude 插件自带生命周期 hooks，接收统一使用版本校验的原生 socket；移除 Channel 和专用启动流程。[安装与接入说明](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.5/ONBOARDING.md)。

- 用户级 Claude 插件自动加载短 SessionStart/SessionEnd hooks，无需逐项目写设置；Codex 不加载 Claude hooks，继续使用 queue。
- join 自动尝试绑定准确会话的 socket。显式停用保持，不支持的版本明确报告并保留主动读写，无 Channel 降级。
- hooks 使用真实原生身份，仅在已初始化、开启 autoJoin 的工作区自动登记；autoJoin 默认关闭，不初始化无关项目或新 worktree，不登记子 agent。退出时清理准确会话。
- 删除 Channel 接收器、MCP SDK、启动握手和专用恢复入口。旧命令返回 E_RETIRED，迁移停用自有私有启动器，不关闭业务会话。
- 默认 join/install 继续不修改 AGENTS.md、CLAUDE.md、项目 hooks 或 Git exclude。旧消息、游标、预留和 unknown 暂停保留。
- 全局 CLI 和插件均需更新。旧项目固定入口用新版 install 预览并 --apply 更新，再读取该入口 skills get；插件最低 CLI 为 Alpha 5。项目 hooks 仅作为手动兼容选项。

自动化覆盖自动绑定、停用、版本拒绝、权威 SessionStart 重绑、旧 nonce/预留保留、hook 项目边界及 sh 包装；四平台执行检查、构建和无外部 Bun/Node 的独立程序验收后发布。

socket 协议仍锁定 Claude Code 2.1.312 / peerProtocol 1。此前真实收信及长期空闲证据仅适用于原 macOS arm64 交互 CLI 会话；本轮包和插件验证不代表新模型会话已接通。
