# AgentChat v0.1.0-alpha.5

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.5.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.5/ONBOARDING.md).

Claude plugins load lifecycle hooks and reception uses the version-checked native socket. Channel and dedicated startup flows are removed.

- User-level Claude SessionStart/SessionEnd hooks load without project copies; Codex retains queue and does not load these hooks.
- Join binds the exact supported socket, preserves disablement and reports unsupported versions with manual messaging; no Channel fallback.
- Auto-join defaults off and affects only initialized opted-in workspaces. Do not enroll unrelated projects/worktrees or subagents; clean up exact sessions on exit.
- Retire Channel/MCP SDK/handshake/launcher code and owned private launchers without closing user clients.
- Preserve runtime-only defaults, messages, cursors, reservations and unknown pauses. Upgrade global CLI/plugin and explicitly repair project pins.

125 local tests and initial PR/main checks passed, but the tagged Linux arm64 build failed a concurrent-writer test. No Alpha 5 installation packages were published. Alpha 6 delivered this functionality and its fix; the tag was preserved.

Native proof remained limited to the original macOS arm64 Claude Code 2.1.312 / peerProtocol 1 interactive session.
