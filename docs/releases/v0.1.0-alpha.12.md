# AgentChat v0.1.0-alpha.12

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.12.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.12/ONBOARDING.md).

Addresses [issue #12](https://github.com/ccsang/agentchat/issues/12): stale Claude bindings and unverified Codex reception now explain the actual problem and next step while preserving exact-peer routing and notification reservations.

- Separate pre-submit validation from connection failures with fixed sanitized codes/causes and reservation_consumed false. Native JSON/parser failures cannot expose credentials in send/doctor output.
- Provide exact-project/room/member repair preview/apply argv for stale bindings. Diagnostics never select another process, resend old attempts or clear pauses.
- Distinguish configured project hooks from observed SessionStart source/PID/time/workspace. Missing observation does not prove plugin absence; stale bindings receive an install/load hint without automatic configuration changes.
- Explain Codex no_nonce_proof separately from queue-command capability. Help/version availability and queue receipts never verify a target thread; an authorized reverse probe and native-session reply are required.
- Keep Claude 2.1.312 as the minimum baseline with no upper product-version limit. New diagnostics do not inherit or create native-model proof.

Upgrade the global CLI and requested projects' pinned entries. Refresh existing owned project hooks only within that explicit scope; the unchanged Alpha 8 thin plugin remains compatible. Diagnostics and repair previews send no real model notifications.

Validation: 176 local tests, type checking, source build and macOS arm64 standalone checks passed. Compiled fixtures checked sanitized stale repair, credential redaction, lifecycle observations and Codex command capability without new model proof or real native notifications. Four-platform and public-upgrade checks gate and follow publication.
