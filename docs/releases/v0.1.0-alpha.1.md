# AgentChat v0.1.0-alpha.1

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.1.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.1/ONBOARDING.md).

Native-session collaboration with standalone macOS/Linux (glibc) arm64/x64 packages. The fixed-version HTTPS installer selects the platform, verifies SHA-256, previews/backups project setup and preserves existing configuration. No source clone or external Bun/Node is needed.

The core is one CLI, SQLite and members/messages. Persisted messages, submitted notices and model processing are separate; reads require explicit marking. Unknown submission pauses without replay.

At this historical release Claude defaulted to Channel with an explicitly selected native socket experiment; Codex used queue. The original macOS arm64 Claude Code 2.1.312 / peerProtocol 1 interactive session passed socket nonce, bidirectional and sequential real 10-minute/hour idle checks. Each user/session still needs its own verification. Windows packages and other native-model combinations were not accepted. Gateway, authentication, inbound and tool permissions were preserved.

Packages include SHA256SUMS, LICENSE and THIRD_PARTY_LICENSES.txt.
