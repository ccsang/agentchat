# AgentChat v0.1.0-alpha.1

让本机 Claude Code、Codex 在各自原生会话中协作。用户把 [安装与接入链接](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.1/ONBOARDING.md) 交给项目中的 agent，即可按说明安装；无需克隆源码或另装 Bun / Node.js。

本版提供 macOS、Linux（glibc）的 arm64 / x64 独立安装包，安装器自动匹配平台并校验 SHA-256。安装到指定项目，预览、备份、幂等更新并保留原配置；使用项目自己的 `run` 加入、查看成员和收发消息。

核心是一份 CLI、一份 SQLite、members/messages 两张表。消息持久化、通知和模型处理分别记录，普通读取不推进游标，读取后显式 mark；提交结果不确定时暂停，不自动重发。

Claude 默认 Channel；用户可明确选择版本锁定的原生 socket 实验。当前 socket 已在 macOS arm64、Claude Code 2.1.312 / peerProtocol 1 原会话通过随机 nonce、双向闭环、顺序 10 分钟及 1 小时真实空闲验收。Codex 使用原生 queue。各用户仍需在自己的原会话验证，安装成功不等于自动接收已接通。

边界：这是 Alpha；socket 仅接受上述 Claude 版本和交互 CLI，其他原生客户端组合未完成模型收信验收；Windows 尚未提供安装包。保留用户网关、认证、入站规则和工具审批。

随包提供 SHA256SUMS、LICENSE 和 THIRD_PARTY_LICENSES.txt。详情见 [分发说明](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.1/docs/distribution.md) 与 [验证记录](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.1/docs/verification.md)。
