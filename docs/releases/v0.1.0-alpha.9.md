# AgentChat v0.1.0-alpha.9

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.9.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.9/ONBOARDING.md).

Fix Claude SessionStart hooks failing with ENOENT when CLAUDE_ENV_FILE does not exist yet after startup, resume or compaction. Integrates the user-provided 986b3c3 patch.

- Resolve the absolute path's existing parent and create/open only its leaf without following links. New files use 0600.
- Validate the opened descriptor as a regular file owned by the current user, preserve existing content/newlines and avoid duplicate identity exports on repeated calls. Always close the descriptor.
- Reject links, non-regular targets and missing parents without creating unrelated state.
- Upgrade the global CLI, then explicitly refresh each affected project's pinned executable/agentchat.js. Existing managed project hooks that still invoke an old executable also need a scoped install --hooks preview/apply; plugin-only projects need no project hook copy.

The plugin wrapper and skill are unchanged (Alpha 8 remains compatible). Storage, notification routing, inbound-policy choices and reservations are unchanged. Compact regression and standalone checks use isolated synthetic hook input; no new real-model reception is claimed.

Validation: 141 local tests, type checking, source build, standalone plugin/managed-hook checks and navigation/language checks for 36 English/Chinese documents passed. Four native targets gate publication.
