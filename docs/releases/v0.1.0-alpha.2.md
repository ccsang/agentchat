# AgentChat v0.1.0-alpha.2

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.2.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.2/ONBOARDING.md).

Install the program once, initialize a project on first join, and create/select rooms separately.

- The installer provides a global command; later sessions reuse it.
- Room create/list/current/use keep selection per native session, preserving history, cursors and reservations.
- Explicit --room routes a single message operation without changing selection; late notices retain the original room.
- The historical Channel followed room selection; socket endpoints were reusable but nonce proof stayed room-specific and unknown pauses crossed rooms.
- Preserve the default database and two-table model. Older active Channels needed exact-session recovery through the newer entry before switching rooms.

126 local tests passed. Four native runners verified standalone packages before release. Synthetic room switching was not new real-model reception evidence; the socket experiment remained restricted to Claude Code 2.1.312 / peerProtocol 1.
