# AgentChat v0.1.0-alpha.8

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.8.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.8/ONBOARDING.md).

Configure Claude's inbound policy explicitly before startup, and read the project documentation in English with Chinese translations available.

- New `claude-inbound` inspects or previews user-level accept/hold/refuse/default without a project or native identity; --apply backs up existing settings and updates only the requested policy.
- Accept persists across launches. In initialized workspaces, the Claude startup hook displays the configured policy, preserving later hold/refuse choices and leaving unrelated projects silent.
- Accept covers all peer messages in that Claude configuration, not just AgentChat. Ordinary installation/join does not enable it. Managed/launch/stricter project settings still apply.
- Doctor distinguishes the configured user value from effective native policy and verified model reception.
- English onboarding covers assisted setup, UI/per-launch alternatives, precedence, reversal and old held messages. Primary docs/release notes and generated instruction blocks are English; Chinese translations live under docs/zh-CN.

Storage, notification routing, limits, reservations and native-version restrictions are unchanged. Configuration and synthetic/package checks are not new real-model reception evidence.

137 local tests, type checking, source build, standalone package checks, plugin validation and 34-document navigation/language checks passed. Four-platform native checks gate publication. No real model notifications were sent for this revision.
