# AgentChat v0.1.0-alpha.13

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.13.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.13/ONBOARDING.md).

- `leave` exits the current native session's selected room without switching to another room or affecting other threads. Member identity, message history, read position, reservations and pauses are preserved.
- `members` distinguishes joined and left membership without claiming online status. An explicit `join` rejoins the last room left; an explicit room selection can join another room. Historical reads remain available through the original room.
- Claude lifecycle hooks respect explicit exit even with autoJoin enabled. Notification submission is serialized with exit; already submitted notices can still arrive, and rejoin itself does not retry pending messages.
- Globally loaded plugin hooks stay quiet in home/root but report actual Git discovery failures. Probe proof failures are reported separately from notification outcomes. Explicit project integrations preserve existing project-file permissions.

Upgrade the global CLI and every participating project entry or managed hook before relying on leave; older executables do not implement the exit state and notification lock. The thin plugin remains unchanged. No database schema migration is required.

Automated verification uses isolated native-session fixtures and compiled packages. Installation, a socket write or synthetic tests do not establish real model reception; a fresh authorized reply from the exact native session is required.
