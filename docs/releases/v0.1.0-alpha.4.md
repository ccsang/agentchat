# AgentChat v0.1.0-alpha.4

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.4.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.4/ONBOARDING.md).

Plugins provide a shared thin discovery skill; the complete collaboration protocol updates with the CLI.

- Claude/Codex marketplaces reference one plugin and skill, recommended at user scope.
- Skills list/get/JSON read compiled instructions without project initialization or native identity; JSON includes version and SHA-256.
- The thin skill stores no project/member/room. At this historical milestone plugins had no lifecycle hooks or MCP runtime.
- Global upgrades do not replace project pins. Preview/apply a requested project's runtime repair with the newer CLI, then read that exact entry's protocol.
- The host manages plugin updates; the CLI never overwrites caches or every project's version.

139 local tests covered read-only/no-context use, errors, hashes, private bundles and shared manifests. Four-platform standalone checks and isolated plugin installs do not prove model-triggered discovery or automatic reception.
