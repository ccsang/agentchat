# AgentChat v0.1.0-alpha.4

插件提供薄 skill，完整协作规范随 CLI 更新。[安装与接入说明](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.4/ONBOARDING.md)。

- Claude Code 和 Codex 的仓库 marketplace 指向同一个 AgentChat 插件，共用一份发现入口 skill。建议用户级安装，各项目复用。
- 新增 skills list、skills get [agentchat] 和 --json；无需项目初始化或原生身份，直接读取实际可执行文件中编译的完整规范，JSON 同时返回 CLI 版本和 SHA-256。
- 插件不保存业务项目路径、成员或房间，没有自动执行 hooks/MCP。程序安装器只安装 CLI；使用工具时才按用户请求准备项目。
- 项目入口仍固定引用安装时版本。升级全局程序后，用新版 install 预览并应用需升级项目的本地入口，再读取该入口的 skills get；不要把新版规范用于旧二进制。旧管理块和 hooks 不自动修补或删除。
- 薄 skill 通过宿主插件机制更新；完整规范随 CLI 发布，下次使用重新读取。CLI 不改写插件缓存，插件升级也不替换所有项目的固定版本。

139 项测试覆盖无项目/身份的只读读取、错误拒绝、协议内容哈希、安装后私有 bundle 内置规范及共享插件目录。四平台运行类型检查、测试、构建和独立程序验收后发布。插件识别和协议读取不代表模型已自动触发 skill，也不构成新的原生收信证据。
