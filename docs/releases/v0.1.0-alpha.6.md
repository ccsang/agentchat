# AgentChat v0.1.0-alpha.6

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.6.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.6/ONBOARDING.md).

Deliver Claude lifecycle hooks and native socket reception, retiring Channel/MCP/dedicated launchers, plus a concurrent SQLite opening fix.

- Claude plugin hooks load automatically; Codex continues using queue.
- Join binds the exact supported session, preserves disablement and reports unsupported versions without fallback.
- Auto-join remains opt-in for initialized workspaces; cleanup and identity checks preserve project/subagent boundaries.
- Default join/install leaves business instructions/hooks/exclude unchanged. Preserve messages, cursors, reservations and unknown pauses.
- Upgrade global CLI/plugin and explicitly preview/apply project-pin repair. Project hook copies remain optional.

The SQLite fix tolerates a journal being removed between inspection calls, while still rejecting unsafe permissions/links; failed concurrent workers now print stderr. Alpha 5 had no published packages after its failed tag check. 127 local tests and four-platform standalone verification passed for this release.

Historical native acceptance remains scoped to the original macOS arm64 Claude Code 2.1.312 / peerProtocol 1 interactive session.
