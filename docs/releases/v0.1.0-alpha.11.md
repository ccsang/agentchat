# AgentChat v0.1.0-alpha.11

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.11.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.11/ONBOARDING.md).

Claude Code 2.1.312 is now the minimum baseline instead of an exact-version allowlist. Higher patch, minor and major versions can join, resume and receive automatically through the implemented peerProtocol 1 interactive CLI adapter. A newer product version alone never disables reception.

- Compare semantic versions numerically, including prerelease precedence and build metadata.
- Report below-baseline/malformed versions as E_PEER_VERSION, actual wire-protocol incompatibility as E_PEER_PROTOCOL and incompatible client kind as E_PEER_KIND.
- Preserve exact UUID/project/process/socket/credential checks, explicit disablement, reservations, pauses and receiver-proof isolation.
- Cover newer-version join and submission, upgrade/resume and explicit repair using isolated synthetic peers. No ordinary test notifies a real model, and historical nonce proof does not verify a newer instance.

Upgrade the global CLI and the requested projects' pinned entries; explicitly refresh already-enabled owned project hooks if they still invoke an older executable. The unchanged Alpha 8 thin plugin remains compatible. Diagnose and fix actual host compatibility failures rather than adding product-version ceilings.

Validation: 166 tests, type checking, source build, macOS arm64 standalone verification without external Bun/Node, and all 40 English/Chinese document checks passed. The compiled baseline-to-newer-major resume and explicit repair checks used a synthetic peer with zero connections; no real-model notification was sent.
