[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.7/ONBOARDING.md).

Notifications become three lines, with full rules loaded only when needed.

- Keep provenance, message IDs and exact Read argv including executable/project/room.
- Remove Base64 routing, duplicate identity/path fields, links and repeated rules; business bodies stay in SQLite.
- The thin skill recognizes Read argv and legacy Tool argv. Reuse the same entry/version's loaded protocol, reloading when missing or changed.
- Preserve exact arguments for special-character paths and late original-room reads/replies/contiguous marks after a room/cwd change.
- For the same sample, one notice fell from 1326 to 242 bytes (about 82%); a 20-message batch from 2124 to 1040 (about 51%). These are bytes, not model token measurements.

Update the program/plugin and explicitly preview/apply each requested project's private-entry update. Global upgrades do not replace all pins. Storage, adapters, limits and reservations are unchanged. 129 local tests, four-platform packages and public upgrade/plugin verification passed; no new real-model notifications were sent.
