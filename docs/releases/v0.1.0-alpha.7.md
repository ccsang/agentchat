# AgentChat v0.1.0-alpha.7

消息提醒缩为三行，完整协作规则按需读取。[安装与接入说明](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.7/ONBOARDING.md)。

- 每次通知仅保留来源标识、消息 ID、Read argv 参数数组；读取命令已包含准确 CLI、项目与房间。
- 移除 Base64 路由、重复目录/身份字段、文档链接和整段操作规则。正文仍存于 SQLite。
- 薄 skill 同时识别新 Read argv 与旧 Tool argv。已加载的同入口/版本规范复用，首次使用、入口/版本变化或上下文缺失时才 skills get。
- 切房后和其他 cwd 收到迟到通知，仍可按准确参数读取、回复并标记连续游标。路径中的空格和引号由 JSON 数组保留。
- 同一示例路径下，单条提醒由 1326 字节降至 242 字节（约 82%）；20 条合并提醒由 2124 降至 1040 字节（约 51%）。这是通知字节对比，不是模型 token 测量。

升级程序和插件后，用新版 install 预览并应用需升级项目的私有入口，再按需读取其 skills get。项目固定版本不会被全局升级批量替换；默认 join 继续不修改业务项目指令和 hooks。

存储、通知适配器、限流和预留行为不变，不新增真实模型收信证据。
