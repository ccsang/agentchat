# AgentChat v0.1.0-alpha.10

English | [Chinese translation](../zh-CN/releases/v0.1.0-alpha.10.md)

[Install and onboard](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.10/ONBOARDING.md).

Restore an already-joined Claude session after restart/resume even with autoJoin off. Previously SessionEnd inactivated the selected named room, while SessionStart restored only the base session and skipped rebind when new-session auto-join was disabled.

- Look up the exact existing runtime/UUID in the selected room; preserve member/name/cursor/selection. With autoJoin off, open existing data read-only and never create a member or room.
- Revalidate/rebind through existing native-process/version checks. Preserve explicit disablement, uninstall and uninitialized-worktree/subagent boundaries.
- Keep nonselected rooms inactive, old receiver proof historical, and budgets/pauses/reservations unchanged. Startup never sends or replays notifications.
- Explicit socket-config --apply also reactivates an existing ended room after validating its live peer, without fabricating a native hook or requiring another join.
- New UUIDs still need explicit join or autoJoin; a matching name cannot take over membership. Setup reports existing/created membership and binding results.

Upgrade the global CLI and affected project pins/owned hooks; the unchanged Alpha 8 plugin remains compatible. Let the host run its real SessionStart after upgrading a live session. Synthetic peer/package checks are separate from actual native-model nonce verification.

Validation: 147 local tests, type checking, source build, compiled macOS arm64 package checks and navigation/language checks for all 38 English/Chinese documents passed. The synthetic peer received no connections; no real-session notification was sent.
