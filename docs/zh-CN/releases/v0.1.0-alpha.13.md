# AgentChat v0.1.0-alpha.13

- `leave` 只退出当前原生会话所选房间，不自动切房、不影响其他 thread；保留成员身份、历史、阅读进度、预留和暂停。
- `members` 区分 joined 和 left，不推断在线。显式 `join` 恢复最近退出的房间；指定房间可加入其他已有房间，原房间历史仍可只读。
- 即使开启 autoJoin，Claude 生命周期 hooks 也不会撤销退出。通知提交与退出串行；已提交的通知仍可能迟到，重新加入本身不会重试待发送消息。
- 全局插件 hooks 在 home/root 保持静默，真实 Git 发现故障正常报错。probe 证明失败与通知结果分开；显式项目集成保留已有项目文件权限。

使用退出功能前，升级所有参与者的全局 CLI、项目固定入口及已有托管 hooks；旧程序不支持退出状态及通知锁。薄插件不变，无需迁移数据库 schema。

自动验证使用隔离的原生会话模拟和编译安装包。安装、socket 写出及模拟测试都不能证明真实模型收信；仍需当前准确原生会话在授权范围内返回新回复。
