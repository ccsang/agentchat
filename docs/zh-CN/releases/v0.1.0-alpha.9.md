# AgentChat v0.1.0-alpha.9

修复 startup、resume、compact 后 CLAUDE_ENV_FILE 尚未创建导致 SessionStart 的 ENOENT，集成用户补丁 986b3c3。[接入说明](../ONBOARDING.md)。

- 绝对路径只规范化已有父目录，不跟随叶子链接，新建权限 0600。
- 对描述符校验普通文件和用户所有权，保留内容、换行及重复调用幂等，始终关闭描述符。
- 拒绝链接、非普通文件和缺失父目录，不创建无关状态。
- 升级全局 CLI 后显式刷新受影响项目的固定入口/agentchat.js；原有托管项目 hooks 若仍指向旧程序，还需 install --hooks 预览应用。仅使用插件的项目不需要项目副本。

插件脚本及 skill 不变，Alpha 8 插件继续兼容。消息存储、通知路由、入站选择及预留不变。compact 验证使用隔离模拟输入，不代表新增真实模型收信证据。
