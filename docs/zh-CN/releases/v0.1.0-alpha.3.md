# AgentChat v0.1.0-alpha.3

默认加入只准备本地运行状态，AGENTS.md、CLAUDE.md 和 Claude hooks 改为独立的可选集成。[安装与接入说明](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.3/ONBOARDING.md)。

- join、room use 和默认 install 不读取或修改项目指令、.claude/settings.local.json 或 Git exclude；已有文件已入库、配置损坏或有旧管理块时同样适用。Git 项目运行状态仍全部位于 Git 元数据目录。
- install --instructions 和 install --hooks 分别预览对应改动，--apply 才应用；uninstall 的相同标志可分别移除，保留本地运行能力和消息。不同 worktree 的集成选择独立保存。
- 通知自带准确 CLI、项目、房间与消息 ID，不要求业务项目存在 ONBOARDING.md 或指令管理块。Channel 需要明确启用 hooks 及宿主功能，socket 实验与 Codex queue 不依赖这些项目文件。
- 程序仍本机安装一次，项目首次加入准备本地状态，聊天室独立创建和选择；没有新增服务、端口或数据库表。

Alpha 1/2 的默认 join 会改项目文件。升级时先运行新版安装器，再用全局新版 join 刷新旧项目入口，并检查 --version；原入口可能仍固定引用旧程序。旧管理块和 hooks 保持原样，不自动删除或修补；需要时明确选择对应 install/uninstall 标志。

本机 135 项测试、类型检查、构建和独立程序验收通过；四平台原生流水线全部通过后发布安装包。安装和协议测试使用合成会话，不构成新增真实模型收信证据；用户仍需在自己的原会话验证。socket 实验继续限定已验收的 Claude Code 2.1.312 / peerProtocol 1 组合，Windows 暂无安装包。
