# AgentChat v0.1.0-alpha.8

在启用自动收信时帮助设置 Claude 入站策略；主文档改为英文，保留中文翻译。[接入说明](../ONBOARDING.md)。

- 新增 claude-inbound，只读检查或预览 accept/hold/refuse/default，--apply 精确备份并仅更新用户级收信项，无需项目或会话身份。
- Accept 保存一次，后续 Claude 启动沿用；已初始化工作区的 hook 显示当前用户设置，保留后来选择的 hold/refuse，无关项目静默。
- Accept 影响该 Claude 配置下全部 peer 消息，不限于 AgentChat；普通安装和 join 不启用。组织、启动和更严格项目规则仍有效。
- doctor 将用户配置、未验证的实际策略和模型回传证据分开。
- 英文接入说明补齐 agent 代设、人工/单次启动替代、优先级、撤销和旧通知处理；主文档、历史发布说明和生成的指令块使用英文，中文置于 docs/zh-CN。

存储、路由、通知预算和预留不变。配置及自动化/安装包检查不构成新的真实模型收信证据。
