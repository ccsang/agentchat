# AgentChat v0.1.0-alpha.12

处理 [issue #12](https://github.com/ccsang/agentchat/issues/12)：陈旧 Claude 绑定和 Codex 未验证状态现在解释具体原因和下一步，保持准确 peer 路由与通知预留。[接入说明](../ONBOARDING.md)。

- 提交前区分校验/连接失败，提供固定脱敏 code/cause 和 reservation_consumed=false，原生 JSON 解析失败不会在 send/doctor 中暴露凭据。
- 陈旧绑定提供准确项目/房间/成员的修复预览和应用数组；不选其他进程、不重发旧尝试、不清暂停。
- 项目 hooks 配置与观察到的 SessionStart 来源/PID/时间/工作区分开；没有观察不证明插件缺失，提示安装/加载而不自动改配置。
- Codex no_nonce_proof 与 queue 命令能力分开；help/version、queue 回执不验证目标线程，授权反向探针和原会话 nonce 回复才提供证明。
- Claude 2.1.312 最低基线且无产品版本上限保持；诊断不创建或继承新模型验收证明。

升级全局 CLI 和指定项目固定入口；已有托管项目 hooks 仅在明确范围刷新，Alpha 8 薄插件继续兼容。诊断和修复预览不向真实模型发通知。

验证：本机 176 项测试、类型检查、源码构建和 macOS arm64 独立程序验收通过。编译入口覆盖陈旧绑定修复、凭据脱敏、生命周期观察和 Codex 命令能力，不产生新模型证明或真实原生通知；四平台和公开升级按发布流程另行验收。
