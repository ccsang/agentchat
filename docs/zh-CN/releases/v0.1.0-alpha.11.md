# AgentChat v0.1.0-alpha.11

Claude Code 2.1.312 改为最低基线，不再使用精确版本白名单。更高补丁、次版本和主版本均可通过 peerProtocol 1 交互 CLI 自动加入、恢复和接收，不因产品版本更新而禁用。[接入说明](../ONBOARDING.md)。

- 按语义版本数值顺序比较，包含预发布顺序和构建元数据。
- E_PEER_VERSION 表示低于基线或格式损坏，E_PEER_PROTOCOL 表示真实协议不兼容，E_PEER_KIND 表示客户端类型不兼容。
- 准确 UUID/项目/进程/socket/凭据校验、显式停用、预留、暂停和实例证明隔离保持不变。
- 隔离模拟 peer 覆盖新版加入和发送、升级恢复、显式修复；普通测试不联系真实模型，历史 nonce 不自动验证新实例。

升级全局 CLI 和指定项目的固定入口；已有托管项目 hooks 仍指向旧程序时显式刷新。Alpha 8 薄插件无需变化。遇到实际兼容问题应诊断修复，不增加产品版本上限。

验证：166 项测试、类型检查、源码构建、无外部 Bun/Node 的 macOS arm64 独立程序验收，以及 40 份中英文文档检查均通过。编译入口的基线升级至更高主版本恢复及显式修复使用隔离 peer，连接数为零，未向真实模型发送通知。
