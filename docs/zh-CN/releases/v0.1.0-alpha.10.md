# AgentChat v0.1.0-alpha.10

修复原 Claude 会话恢复后仍需重复 join 的问题。[接入说明](../ONBOARDING.md)。

- 关闭 autoJoin 时，仍按准确 runtime/UUID 恢复所选房间已有成员，保留身份、名称、游标与选房；只读查询，不新建库或成员。
- 原生进程和版本重绑校验保持，显式停用、卸载、未初始化 worktree 和子 agent 边界保持。
- 其他房间不恢复，旧 nonce 不验证新实例，预算/暂停/预留不变，启动不通知或重放。
- 显式 socket-config --apply 校验活跃 peer 后也恢复已有房间，无需伪造 hook 或重复 join。
- 新 UUID 仍需明确加入或启用 autoJoin，同名不能接管；Setup 显示已有/新建成员及实际绑定结果。

升级全局 CLI、受影响项目固定入口和已有托管 hooks，Alpha 8 插件继续兼容。运行中会话需由宿主真实触发 SessionStart；模拟 peer/安装包检查不等于新模型实例收信验收。

验证：本机 147 项测试、类型检查、源码构建、macOS arm64 编译安装包检查，以及 38 份中英文文档导航/语言检查均通过。模拟 peer 未收到连接，本轮未向真实会话发送通知。
