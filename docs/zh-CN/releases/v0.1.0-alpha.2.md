# AgentChat v0.1.0-alpha.2

程序安装一次，项目首次加入自动初始化，聊天室独立创建和选择。[安装与接入说明](https://github.com/ccsang/agentchat/blob/v0.1.0-alpha.2/ONBOARDING.md)。

- 安装器只安装全局程序，默认提供 ~/.local/bin/agentchat，业务项目配置由首次 join 自动准备；后续会话无需重装。
- room create/list/current/use 管理项目内房间，选择按原生会话隔离；切房保留消息、阅读进度及通知预留。
- 明确 --room 的读取、发送和标记不改变默认选择；通知携带房间，迟到消息按原房间处理。
- 一个 Channel 跟随该原生会话的选择。socket 复用已明确选择的端点，各房间仍需自己的 nonce；未知提交暂停跨房间保留。
- 原 default 数据库路径及两张表不变。已有活跃的旧 Channel 需要通过新版启动入口恢复原会话后再切房；不创建替代业务会话。

本机 126 项测试通过。四平台流水线在原生 runner 上运行完整测试和独立程序验收后才发布安装包；另有公开下载验收。房间切换的协议模拟不代表新的真实模型收信结论，用户仍须在自己的会话验证。socket 实验继续限定 Claude Code 2.1.312 / peerProtocol 1，Windows 暂无安装包。
